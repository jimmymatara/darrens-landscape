# Darren's Lawn and Landscape

Official website source for Darren's Lawn and Landscape in West Edmonton, Alberta.

## Local development

```bash
npm install
npm run dev
```

## Production check

```bash
npm run build
npm run preview
```

## Main content

- `src/routes/index.tsx` — homepage content and sections
- `src/routes/__root.tsx` — global metadata and document shell
- `src/styles.css` — global styling
- `src/assets/` — project image references
- `public/favicon.ico` — browser icon
